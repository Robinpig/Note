## Introduction

经济学研究**稀缺资源如何配置**：个人与企业如何做选择（微观），整体经济如何运行（宏观）。核心矛盾是「资源有限而欲望无穷」，因此经济学本质上是一门关于**权衡（trade-off）与激励（incentive）**的科学。本笔记是经济学主题的索引骨架，串起微观、宏观、思想史与博弈论。

## 微观经济学（Microeconomics）

研究单个主体（消费者、企业）在市场中的行为：

- **供给与需求**：价格是供需的均衡结果；需求定理（价格上升需求下降）、供给定理相反。
- **需求弹性**：价格变化时需求量的敏感程度。必需品缺乏弹性（涨价照买），奢侈品富有弹性；弹性决定「涨价是否能增加总收入」。
- **边际分析**：理性决策看边际量而非总量——边际收益 vs 边际成本。**边际效用递减**：同一种东西消费得越多，新增一单位带来的满足越小。
- **成本概念**：
  - **机会成本**：做一个选择时放弃的最优替代项（真正的成本，常被忽略）。
  - **沉没成本**：已经付出且无法收回的成本，理性决策应忽略（不要「来都来了」）。
- **市场失灵**：在**非排他性、非竞争性**的公共品（如国防、路灯）上，自由市场无法有效供给（搭便车问题）；外部性（污染）、信息不对称、垄断同样导致失灵，需要政府干预。
- **市场结构**：完全竞争、垄断竞争、寡头、垄断；**反垄断**与贸易保护是政府对市场势力的规制。

## 宏观经济学（Macroeconomics）

研究经济整体：产出、物价、就业与货币。

| 概念 | 要点 |
| --- | --- |
| GDP | 一定时期内一国生产的最终产品与服务总价值 |
| 通货膨胀/紧缩 | 物价水平持续上涨/下跌；恶性通胀与通缩都有害 |
| 经济萧条/停滞 | 需求不足、产出下降、失业上升 |
| 货币供给 | 央行通过货币量与利率影响总需求 |
| 汇率与贸易 | **货币升值 → 进口增加、出口承压；货币贬值 → 出口增加、进口变贵** |
| 财政/货币政策 | 政府支出税收 vs 央行利率与货币量，两类逆周期调节工具 |

货币与物价的调整存在时滞，短期刺激与长期可持续之间需要平衡，是宏观政策争论的核心。

## 经济学思想史脉络

| 阶段 | 代表人物与著作 | 核心主张 |
| --- | --- | --- |
| 古典经济学 | 亚当·斯密《国富论》《道德情操论》；大卫·李嘉图《政治经济学及赋税原理》；阿尔弗雷德·马歇尔《经济学原理》 | 「看不见的手」、比较优势、供给侧、市场自我调节 |
| 现代/凯恩斯主义 | 凯恩斯《就业、利息和货币通论》 | 大萧条证明市场可能长期失衡，需要**政府干预**管理总需求 |
| 后续发展 | 货币主义、理性预期、新古典综合、行为经济学等 | 对政府边界、预期与非理性行为的持续修正 |

两条主线的张力贯穿始终：**自由市场主义**（相信价格信号与竞争）vs **计划/干预主义**（相信政府纠偏），现实经济多在光谱之间寻找平衡。更多脉络见 [经济学导论](/docs/Economics/经济学导论.md)。

## 博弈论：相互依赖下的决策

当一个人的结果不仅取决于自己、还取决于他人的选择时，就进入博弈论的范畴：纳什均衡、囚徒困境、协调问题、重复博弈等。它解释了寡头竞争、军备竞赛、公地悲剧等「个体理性导致集体次优」的现象，是微观与策略分析的现代工具。详见 [Game Theory](/docs/Economics/Game_Theory.md)，博弈的数学形式化（零和博弈、极小化极大）见 [Zermelo](/docs/Economics/Zermelo.md) 与算法侧的 [Algorithmic Game Theory](/docs/CS/Algorithms/Algorithmic_Game_Theory.md)。
