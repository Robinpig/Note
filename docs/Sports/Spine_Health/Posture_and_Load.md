## Introduction

这一页是颈椎病、腰椎间盘突出、脊柱侧弯三者的共通底座。它刻意**不提供动作清单**——因为颈部、腰部、侧弯三种情况下同一个动作的安全性并不相同，把动作集中在一页，读者会忽略它属于哪一种。动作分别在 [Cervical Spondylosis](/docs/Sports/Spine_Health/Cervical_Spondylosis.md)、[Lumbar Disc Herniation](/docs/Sports/Spine_Health/Lumbar_Disc_Herniation.md) 与 [Scoliosis](/docs/Sports/Spine_Health/Scoliosis.md)。

这一页只回答四件事：**脊柱在不同负荷下会发生什么**、**「姿势」到底该怎么量化**、**疼痛该怎么解读（含红旗信号）**、**康复的进阶该看什么**。这四件事在三病里是同一套语言，所以只写一次。

> [!WARNING]
>
> 本页提供的是判断框架，不是自诊工具。红旗信号一节里的任何一条命中，都意味着停止自行训练并就医，而不是先按本页的建议处理完再看。

## Three Loading Regimes

脊柱的绝大部分日常动作可以被归入三种负荷，而**同一脊柱在三种负荷下的脆弱环节完全不同**。这张表是全部内容的起点——

| 负荷类型 | 日常表现 | 主要承力结构 | 该姿势下的主要风险 | 长期后果 |
| :-- | :-- | :-- | :-- | :-- |
| **屈曲（flexion）** | 弯腰、久坐低头、坐位前倾、弯腰搬物 | 椎间盘前部、后方纤维环、椎间小关节间隙变窄 | 髓核向后压力升高；后方结构被拉开 | 纤维环慢性退变、椎间盘突出、屈曲型侧弯加重 |
| **伸展（extension）** | 久坐后仰身、仰卧位桥式、某些颈后伸动作、站立位后仰 | 椎间盘后部、椎间小关节后部、棘间韧带 | 小关节与后部结构受压集中；狭窄的椎管在此位置更窄 | 椎管狭窄者神经受压加重、后伸型不适 |
| **旋转 / 侧屈** | 搬重物时转身、单侧负重、脊柱侧弯本身 | 椎间盘、钩椎关节、椎间小关节 | 屈曲与旋转叠加时，纤维环破裂风险显著上升 | 单侧突出、侧弯进展 |

这张表的实用价值在于：**它在解释「为什么正确姿势取决于你的解剖」**。同样一个「坐直」的指令，对椎管狭窄者（伸展位更难受）与椎间盘前突倾向者（屈曲位更难受）给出的方向是相反的。因此本库不给「标准姿势」，只给时间参数——原因在下一节。

## Posture as a Time Parameter

「不要低头」「要挺直腰」这类指令失败率高，原因有两：一是它给的是形态目标而人类无法维持形态目标数小时；二是它忽略了**同一个不良体位持续多久才构成问题**。

更可执行的表述是**剂量**：任何体位下，超过某个持续时长后组织内的应力与疲劳开始累积，缩短这个时长就能显著改变总暴露量。这与运动生理里「总量 > 单次强度」是同一条原理，只是对象换成了静态负荷。

| 场景 | 关键量 | 实际可执行的做法 |
| :-- | :-- | :-- |
| 久坐办公 | 连续静坐时长 | 每 30~45 分钟起身活动 2~3 分钟；坐姿变化本身比姿态更有效 |
| 低头看手机 | 单次连续时长与全天累计 | 把设备举到视线水平；单次不超过约 20 分钟 |
| 屏幕高度 | 视线与屏幕的夹角 | 屏幕上缘与视线齐平或略低；笔记本电脑应另配支架与外接键盘 |
| 睡眠 | 颈椎/腰椎的支撑与旋转 | 仰卧时颈部维持生理前凸；侧卧时头颈与躯干成一直线；避免长期俯卧（强制颈椎旋转） |
| 搬重物 | 屈曲 + 旋转的叠加 | 物体贴近身体、抬髋而非弯腰、转身时移动脚步而非扭转躯干 |

这条思路与「姿势不健康」的说法差别在于：后者假设存在一个几何目标，前者承认身体的优势状态是**变化**，干预手段是打断静态性。这在久坐人群里是决定性差别——修正坐姿需要意志力，而每 30 分钟起身不需要。

## How to Read Pain

疼痛解读是本专题最需要小心的一节，因为**它出错时的代价是双向的**：把结构性改变当成紧急问题，会导致不必要的恐慌、休息与检查；把结构性改变当成无关紧要，会错过真正需要处理的少数情况。

### 三个层次的判断

**第一层：症状的分布与行为。** 疼痛的分布线索指向来源（颈段 vs 腰段、是否沿神经根放射、是否伴自主神经症状），但**分布不能定位到具体结构**。真正有判别力的是症状的**行为模式**：什么动作诱发、什么体位缓解、夜间是否痛醒、晨起是否僵硬、活动后是否减轻。这些模式比任何一次查体都更能区分机械性疼痛与非机械性疼痛。

**第二层：影像与症状的分离。** 这是全页最重要的事实：

- 椎间盘突出在无症状人群中的检出率很高，年龄相关的退变影像改变在多数中年以上人群中属于常态。
- 影像上看见的改变，与此刻疼痛的强度、与未来几周的恢复速度，**没有可靠对应关系**。
- 因此影像不作为「是否有问题」的判据，只在结果可能改变处置时才做。这一点在腰痛领域尤其明确：非专科场景下不常规安排影像，多数情况下结果并不会改变管理方式。

**第三层：红旗信号。** 见下节。这是唯一不能自我判断的层。

### The Red Flags

以下任一项命中，含义是**不要按本专题继续自我训练，直接就医**：

| 类别 | 信号 | 为什么要紧 |
| :-- | :-- | :-- |
| 脊髓 / 圆锥受压 | 步态不稳、踩棉花感、精细动作障碍（系扣、持筷）、手部肌萎缩、进行性肌力下降 | 神经功能损害进展后可能不可逆，属优先处理类 |
| 马尾综合征 | 新发的大小便功能障碍、鞍区（会阴部）麻木 | 需紧急处理，属急诊或准急诊范畴 |
| 血管性 | 转头相关的眩晕、视物模糊、晕厥或猝倒 | 需排除血管来源，运动方案在此之前不适用 |
| 全身性 / 感染性 | 夜间静息痛、发热、体重下降、既往癌症史、免疫抑制状态、近期感染 | 提示非机械性病因 |
| 炎性 | 晨起僵硬超过 30 分钟且活动后明显改善、年轻男性、附着点疼痛 | 提示强直性脊柱炎一类病因，运动方案完全不同 |
| 严重外伤 | 明确外伤后出现的疼痛，尤其伴畸形或四肢症状 | 需先排除骨折与不稳 |

这张表本身就是本专题存在的意义：**红旗信号不需要专业知识，需要的是知道它长什么样，并在出现时停止自我处理。**

## Graded Exposure and How to Progress

康复的目标是**恢复负荷耐受度**，不是消除疼痛。这两者的差别决定了一切做法。

疼痛来自敏感的组织，而敏感的组织会随时间不敏感化。促成敏感化的因素——恐惧、活动回避、久坐不动、恢复不足、睡眠差——与解除它的手段是同一批，只是方向相反。因此「保护」在康复里的含义与直觉相反：**回避与减负会降低负荷耐受度，而降低的负荷耐受度正是复发的主因**。

### 判断依据：24 小时规则

**不要看训练当时的感觉，要看训练后 24 小时的反应。**

| 训练后 24 小时的表现 | 判读 | 该做什么 |
| :-- | :-- | :-- |
| 症状回到训练前水平 | 负荷在耐受范围内 | 按计划进阶 |
| 症状加重但在 24 小时内回到训练前水平 | 仍在耐受边界上 | 同一负荷多做几次，或小幅增加幅度 |
| 症状加重且持续超过 24 小时 | 超出耐受 | 退回上一级，进展速度而非方向需要调整 |
| 出现新的远端症状（放射痛、麻木范围扩大） | 不是耐受问题，需重新评估 | 停止并复诊 |

最后一行的意义是：**新增的远端症状不属于「训练后的正常反应」**。训练后局部肌肉酸痛属正常，而放射痛、麻木范围扩大、新的无力不属于。

### 进阶的两个变量

负荷的进阶只有两个变量需要调，方向明确且没有第三种：

- **量**：次数、组数、时长。优先加这一项。
- **幅度**：关节活动范围、负重、杠杆长度、难度分级。在量能维持且 24 小时无反应后再加。

顺序是有理由的：量改变的是**耐力与耐受时间**，幅度改变的是**结构要求**。多数人的问题不在结构要求太弱，而在从未让结构承受过足够长的持续时间——这也是为什么「练到很痛」和「练很久都不痛」是两个不同阶段的适应。

三个病种在这一点上共享原则，但**结局预期不同**：颈型问题与多数腰痛的终点是恢复负荷耐受；腰椎间盘突出的多数病例有自限倾向，负荷渐进的作用是防复发而非治结构；青少年侧弯的目标常是**稳定**而非矫正，判读节奏由生长速度而非症状决定。这三种不同的判读方式分别在三个病种页展开。
