## Introduction

行为主义（Behaviorism）主张心理学只应研究**可观察的行为**，把「意识」「心理」等不可观测概念逐出科学领域。它由 Watson 在 1913 年正式立论，经 Skinner 推向顶峰，主导了 20 世纪上半叶的美国心理学，直到认知革命把它推下中心位置。

它的正当性在于**可操作化**：刺激（S）与反应（R）都能被客观测量，因而行为主义在实验严谨性上远超内省传统。它的局限也在于此——把「黑箱」整个排除在外，无法解释语言、创造力等复杂现象。

## 经典条件反射（Classical Conditioning）

Pavlov 的狗实验：原本中性的铃声反复与食物配对后，单独响铃也能引发唾液分泌。

| 术语 | 含义 |
| --- | --- |
| 无条件刺激 US | 天生能引发反应（食物） |
| 无条件反应 UR | 天生的反应（分泌唾液） |
| 条件刺激 CS | 原本中性、经配对获得意义（铃声） |
| 条件反应 CR | 对 CS 习得的反应 |

- **习得、消退与自发恢复**：条件反应可建立、可消退，但消退不等于遗忘。
- **泛化与辨别**：相似刺激引发同类反应，或学会区分不同刺激。
- **经典案例**：Watson 的小阿尔伯特实验用条件反射制造了恐惧，展示了情绪也可被条件化。

## 操作条件反射（Operant Conditioning）

Skinner 主张行为受**后果**控制：

| 手段 | 呈现/移除 | 效果 |
| --- | --- | --- |
| 正强化 | 给予愉快刺激 | 行为增加 |
| 负强化 | 移除厌恶刺激 | 行为增加 |
| 正惩罚 | 给予厌恶刺激 | 行为减少 |
| 负惩罚 | 移除愉快刺激 | 行为减少 |

- **强化程序**：固定/变动比率与间隔。**变动比率**（如赌博）最能产生高且难消退的行为——这解释了成瘾与上瘾式产品设计。
- **塑造（shaping）**：逐步强化渐进接近目标的行为，是行为训练与技能习得的基础技术。

## 从行为到观察学习

纯粹的行为主义难以解释「没有直接强化也能学会新行为」。Bandura 的**社会学习理论**补上这一环：儿童通过观察榜样习得攻击行为（Bobo 玩偶实验），**替代强化**与**自我效能**成为关键概念。这一步把行为主义引向了认知——同一条刺激—反应链条里，开始出现「预期」「信念」等内部变量。

## 当代应用

- **行为矫正与应用行为分析（ABA）**：用强化原理改变行为，常用于自闭症干预与习惯养成。
- **习惯回路**：提示 → 惯常行为 → 奖赏，是行为主义原理在产品与个人管理中的现代版本。
- **暴露疗法**：基于消退原理治疗恐惧与焦虑，见 [临床与异常心理学](/docs/Psychology/Clinical_Psychology.md)。
