## Introduction

生理心理学（Biological Psychology，又称生物心理学、行为神经科学）研究**行为与心理过程的生理基础**：神经元如何传导信号、脑区如何分工、神经递质与内分泌如何调节情绪与动机、基因如何影响行为。它是心理学走向**可还原、可观测**的一端——任何认知或情绪现象，最终都要落到神经活动上。

它与 [认知心理学](/docs/Psychology/Cognitive_Psychology.md) 是一体两面：后者用行为指标推断「加工过程」，前者用神经指标追问「加工发生在哪里、由什么实现」。

## 神经元与信号传导

- **神经元**：树突接收、胞体整合、轴突传导、突触释放。
- **动作电位**：膜电位达到阈值后产生「全或无」的放电，强度由**放电频率**编码而非幅度。
- **突触传递**：神经递质（多巴胺、血清素、去甲肾上腺素、GABA、谷氨酸等）跨突触间隙作用于受体，决定兴奋或抑制。
- **可塑性**：长时程增强（LTP）与长时程抑制（LTD）是学习与记忆的细胞机制——「一起放电的神经元连在一起」（Hebb 法则）。

## 脑的宏观组织

| 结构 | 主要功能 |
| --- | --- |
| 脑干 | 呼吸、心跳等生命维持 |
| 小脑 | 运动协调、平衡、部分认知 |
| 丘脑 | 感觉信息的中继站（嗅觉除外） |
| 杏仁核 | 恐惧、情绪显著性、威胁检测 |
| 海马 | 情景记忆的形成与空间导航 |
| 前额叶 | 执行控制、计划、抑制冲动 |
| 胼胝体 | 左右半球的通信 |

**功能偏侧化**：左右半球在语言（多偏左）与空间/情绪加工上各有侧重，但绝大多数任务由双侧协同完成，「左脑理性/右脑感性」是被过度简化的流行说法。

## 研究方法

- **脑损伤法**：从病例（如 Phineas Gage、H.M.）反推脑区功能，因果清晰但不可控。
- **电生理**：EEG/ERP 提供毫秒级时序，空间分辨率低。
- **功能成像**：fMRI 靠血氧信号、PET 靠代谢，空间分辨率高但时间慢，且**相关不等于因果**。

## 递质、内分泌与行为

- **多巴胺**：奖赏预测误差与动机，与成瘾相关（而非简单的「快乐分子」）。
- **血清素**：情绪调节、睡眠，与抑郁药物的作用靶点相关。
- **皮质醇**：应激反应的核心激素，长期升高损害海马与免疫。
- **基因与行为**：行为遗传学用双生子与领养研究分离遗传与环境贡献；多数行为特征是**多基因**的，且基因表达受环境调节（表观遗传）。
