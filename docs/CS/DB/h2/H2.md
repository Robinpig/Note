## Introduction

[H2](https://www.h2database.com/html/main.html) 是纯 Java 编写的开源嵌入式关系型数据库，以极小体积（约 2.5 MB jar）和高性能著称，常作为开发/测试或轻量应用的嵌入式存储。

## 主要特性

- 纯 JDBC API，ANSI SQL 兼容，支持事务、外键、视图与窗口函数。
- **三种运行模式**：
  - **Embedded（嵌入式）**：应用进程内直接读写文件，最低延迟。
  - **Server（服务端）**：TCP/PG 协议，多连接共享。
  - **In-Memory（内存）**：数据仅驻内存，重启即失，适合单测。
- 基于 Web 的 Console 管理界面（浏览器操作）。
- 兼容 PostgreSQL 模式、支持加密数据库（AES）。

## 存储引擎：MVStore

- H2 2.x 默认 **MVStore**（MVCC + B-tree），替代旧 PageStore。
- 写时复制（copy-on-write）B-tree 页，append-only 文件 + 后台 checkpoint，崩溃恢复简单。
- 支持 MVCC 快照隔离，读不阻塞写。

## 适用场景与取舍

- 适合：开发/单测、桌面应用、边缘/嵌入式设备、轻量分析。
- 不适合：高并发多写、超大数据集（无分布式能力）——此时选 PostgreSQL/MySQL。
- 与 SQLite（C 库、零依赖）、Derby（纯 Java）同属嵌入式 RDBMS 阵营，H2 以性能与 Web Console 见长。
