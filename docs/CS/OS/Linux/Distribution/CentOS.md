## Introduction

> 2020年12月08日，CentOS官方宣布了停止维护CentOS的计划，并推出了CentOS Stream项目

CentOS 曾是 RHEL 的免费二进制克隆（下游重建），因"稳定免费的企业级系统"而广泛部署于生产环境。转型后格局变为：

- **CentOS Stream**：滚动预览 RHEL 下一个 minor 版本的构建场——不再是 RHEL 的克隆，而是"略超前于 RHEL"；
- **Rocky Linux / AlmaLinux**：社区发起的 RHEL 兼容重建（1:1 二进制兼容），接棒原 CentOS 的生态位。

Red Hat 系包管理与 [Fedora](/docs/CS/OS/Linux/Distribution/Fedora.md) 相同：`dnf`/`yum` + rpm。
