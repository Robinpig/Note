## Introduction

火山引擎 HiAgent 是字节跳动面向**中大型企业与政企**的一站式企业级智能体全生命周期工作站。它和同样出身字节的 [Coze](/docs/CS/AI/LLM/Coze.md) 是两条独立产品线，分工非常清楚：

- **Coze（扣子）**：SaaS 云端为主，面向个人、创作者和中小企业，卖点是快速搭建与多渠道发布；
- **HiAgent**：企业级 AI 基础设施，面向金融、制造、政务等有强合规要求的行业，卖点是**私有化部署、权限管控、审计合规与大规模 Agent 集群管控**。

一句话区分：**Coze 是给个人做助手的，HiAgent 是给企业造"数字员工工厂"的。**

版本线：2025 年春季 FORCE 大会发布 HiAgent 2.0；**2026 年 6 月 23 日 FORCE 原动力大会迭代至 3.0**，完成了全域「1+N+X」架构的重构。

## HiAgent 3.0 的能力面

### 组织化协同：AgentSphere

3.0 最大的变化是把 Agent 从"单个对话助手"提升为**可被管理的组织成员**：

- **人 + 员工 + 多智能体三方同空间协同**：真人员工、业务数字员工、后台调度 Agent 共享同一套文档、工单与数据视图，支持多人批注、任务分派、跨 Agent 接力处理长流程（如财务结账、设备巡检、政务审批）。
- **数字员工组织化管理**：给智能体设置部门、岗位、权责与 KPI，与真实员工共用一套 RBAC 体系，支持批量"入职 / 离岗 / 权限回收"——这是面向几百上千个 Agent 集群统一管理的前提。
- **全终端统一分发**：原生适配飞书、钉钉、企业微信、自有业务系统、Web/SDK 与私有化客户端，一套智能体同步下发全渠道。

要注意的是：**它的渠道优势与"你在不在字节生态里"高度相关**。飞书集成是天然优势（IM、群组机器人、文档内嵌都能直接 @Agent），但如果你的企业协作底座是企微或钉钉，这部分价值会打折，得看同赛道腾讯 ADP、阿里百炼。

### 系统集成：MCP 3.0 网关

统一以 [MCP](/docs/CS/AI/LLM/MCP.md) 作为企业系统总线：兼容 ERP、SCADA、数据库、IoT 设备与第三方 SaaS，**零代码连接器从 2.0 的 100+ 扩到 300+**；每次系统调用在独立沙箱中执行，配合数据脱敏、操作拦截与完整日志，用于满足等保三级与数据安全法的审计要求。企业内部的插件可统一上架，让不同业务 Agent 复用同一批财务、工单、数据查询工具。

### 开发引擎：低码 / 零码 / 高码三合一

- **自然语言一句话生成完整 Agent**：输入业务描述自动产出工作流、知识库绑定、工具权限、提示词与评测规则；
- **Canvas 3.0 可视化画布**：新增并行分支、循环子流程、异常自动重试、超时降级、人工介入断点，支持子流程模板复用；
- **内置 veRL 强化学习**：可基于生产对话数据自动微调 Agent 决策逻辑，对应 [Self-Evolving](/docs/CS/AI/LLM/Self-Evolving.md) 里"从线上数据反哺迭代"的思路；
- **在线 Python 插件 IDE**：在线调试、一键打包上架内部插件市场。

### DataAgent 与知识侧

多模态混合检索（文档、图纸、产线图片、语音工单、扫描件统一解析），自然语言查数仓（口语问报表/指标/台账，自动出图与归因），以及**数据闭环流水线**：生产对话沉淀 → 自动清洗标注 → 生成微调数据集 → 回流训练，官方宣称无需人工干预。

### 运维与安全

多智能体集群自治调度（自动拆解目标、分派子 Agent、汇总校验）、算力弹性调度（按任务轻重切换轻重模型）、故障自愈与断点续跑；安全侧有 AI 内容防火墙、全链路不可篡改审计日志、内置隐私计算（联邦检索、数据不出域）与知识库/插件/模型/智能体分别授权。

> 上面这些"降本 40%""可用性 99.999%""冷启动 10 ms"属于**官方发布会口径**，选型时应当作诉求清单而非既定事实，实际数字要在 POC 里自己测。

## 与 Coze / Dify 的位置

| 维度 | [Coze 扣子](/docs/CS/AI/LLM/Coze.md) | HiAgent | [Dify](/docs/CS/AI/LLM/Dify.md) |
|------|-------------------|---------|------------------|
| 目标客户 | 个人、创作者、中小企业 | 中大型企业、政企、金融制造 | 各类规模团队（自部署为主） |
| 部署 | SaaS 为主，开源版可自建 | 私有化 / 混合部署 | 自部署为主，也有云版 |
| 治理深度 | 弱（核心流程需另配兜底） | 强（RBAC、审计、隐私计算、内容防火墙） | 中（workspace 权限、日志、评测） |
| 上手门槛 | 最低 | 较高（偏 IT/数字化部门） | 中 |
| 费用 | 低（有免费额度） | 定制报价，门槛较高 | 开源免费 + 云按量 |
| 生态绑定 | 字节渠道（抖音、飞书等） | 飞书 + 火山引擎 + 豆包模型 | 中立，模型与部署自定 |

## 什么时候选它

**选 HiAgent**：已经在用飞书/火山/豆包；数据不能出内网、且有团队或厂商负责交付运维；需要把几百上千个 Agent 当成"数字员工组织"来管；要求等保三级与完整审计追溯。

**不选 HiAgent**：想要快速验证想法或预算有限的团队；需要开放生态与深度二次定制；协作底座不在字节系（这时看 [腾讯云 ADP、阿里云百炼、百度千帆](/docs/CS/AI/LLM/Platform.md)）。
