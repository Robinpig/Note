## Introduction

现象学（Phenomenology）与存在主义（Existentialism）是 20 世纪**大陆哲学**的主干。前者由 Husserl 创立，主张「回到事情本身」，**描述**意识经验的结构而非用自然科学去解释它；后者经 Kierkegaard、Nietzsche 铺垫，在 Heidegger 与 Sartre 手中把焦点转向个体的**存在、自由与荒谬**。

它与英美的分析传统构成 [哲学总纲](/docs/Philosophy/Philosophy.md) 里所说的「两大传统」之一极：分析哲学从 [语言与逻辑](/docs/Philosophy/Philosophy_of_Language.md) 入手，现象学则从**第一人称的经验**入手。

## 现象学方法

- **意向性（intentionality）**：意识总是「关于某物」的意识——这是 Husserl 从布伦塔诺继承的核心洞见，也是现象学与分析哲学心灵哲学的共同议题，见 [心灵哲学](/docs/Philosophy/Philosophy_of_Mind.md)。
- **悬置（epoché）**：把「世界独立存在」这一自然态度**加括号**，只描述呈现出来的经验本身。
- **生活世界（Lebenswelt）**：科学建立在被前科学地经验到的生活世界之上，后者才是意义的源头。

Heidegger 把 Husserl 的「意识」改造为**此在（Dasein）**——一种已经「在世存在（being-in-the-world）」的存在者，并引入「向死而在」「被抛」「本真/非本真」等概念。Merleau-Ponty 则用**身体—主体**反驳纯粹意识的优先性：我们是**通过身体**知觉世界的。

## 存在主义

| 人物 | 核心概念 |
| --- | --- |
| Kierkegaard | 主观真理、信仰的跳跃、个体高于体系 |
| Nietzsche | 「上帝已死」、权力意志、超人、价值重估 |
| Heidegger | 此在、本真性、技术之问 |
| Sartre | 存在先于本质、自由与责任、自欺（bad faith） |
| Camus | 荒谬、反抗、西西弗斯 |

Sartre 的名言「**存在先于本质**」概括了存在主义的核心：人没有预先给定的本质，先存在、再通过选择定义自己——因此「人是被判定为自由的」，逃避选择即为**自欺**。

## 与其它传统的关系

- **与分析哲学**：早期现象学与分析哲学并非绝对对立（弗雷格与 Husserl 有争论，但也有共同的「反心理主义」诉求）；分歧主要在于**方法**——语言分析 vs 经验描述。
- **与西方马克思主义、结构主义**：三者并列为 20 世纪欧洲的思潮，哈马贝斯对它们的批判性综合见 [后形而上学思想-哈马贝斯](/docs/Philosophy/后形而上学思想-哈马贝斯.md)。
- **与心理学**：胡塞尔的现象学方法直接影响了存在主义心理学与[人本主义心理学](/docs/Psychology/Personality_Psychology.md)对「主体经验」的重视，与实证取向的 [认知心理学](/docs/Psychology/Cognitive_Psychology.md) 形成方法张力。
- **与美学**：审美经验的现象学描述（如「审美距离」「崇高」）见 [美学](/docs/Philosophy/Aesthetics.md)。
